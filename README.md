# Cumpleaños de Lizbeth ❤️

Proyecto independiente de la página de Quesos Tena.

## Archivos

- `index.html` — estructura de la página.
- `styles.css` — diseño y animaciones.
- `script.js` — navegación, música, confeti y regalo.
- `imagenes/` — coloca aquí las fotografías.
- `musica/cancion.mp3` — coloca aquí la canción.

## Fotos (20 espacios)

La galería ya tiene 20 espacios. Guarda tus imágenes dentro de la carpeta `imagenes` con estos nombres exactos:

`foto1.jpg`, `foto2.jpg`, `foto3.jpg` ... hasta `foto20.jpg`.

Si una foto no está subida todavía, se mostrará el recuadro que indica qué número de foto falta. Puedes usar JPG; si tus imágenes son PNG o WebP, cambia la extensión correspondiente en `index.html`.

La galería se acomoda automáticamente: 2 columnas en móvil y 4 en pantallas grandes.

## Música

Coloca una canción llamada:

`musica/cancion.mp3`

Si el navegador bloquea la reproducción automática, la música se puede activar con el botón 🔇/🔊.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo, por ejemplo `cumpleanos-lizbeth`.
2. Sube el contenido de esta carpeta.
3. En GitHub entra a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona `main` y `/ (root)`.
6. Guarda y espera a que GitHub publique el sitio.
